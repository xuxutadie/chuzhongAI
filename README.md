# AI 初中学习教练系统

面向初中学生的本地学习工作台。学生可以完成当天任务、保存自己的学习草稿、手动或拍照录入错题；支持自主注册并配置个人 API，或使用教师统一创建与配置的账号。

## 数学衔接诊断（2026-09-25）

学生首次进入会先完成全屏访谈与档案确认，再做六升七数学 24 题测评，查看柱状图、饼图、雷达图并下载六页中文 PDF。支持退出续答、独立复测和历史报告。未配置 AI 时使用明确标注的固定引导与规则诊断。

学生主导航已简化为五项；语文、英语内容和历史数据保留但入口暂时隐藏。已有教师账号后，登录页不再显示首次设置教师。PDF 依赖和中文字体部署请参阅 [数学诊断使用与维护](docs/数学诊断使用与维护.md)。

## 已可使用的学生流程

1. 学生可自主注册（使用个人 API）；教师也可创建管理账号，再单个或批量创建学生账号（使用教师统一 API）。
2. 学生登录后，只能查看自己的今日任务、草稿、错题和成长记录。
3. 学生从已导入的课堂内容中选择知识点，完成诊断、针对学习和过关测试；服务端会重新核验完成条件。
4. 学生可在错题本中拍照、从相册或电脑选图，也可直接手动输入；OCR 只提供待确认文本，确认后才保存。
5. AI/OCR 没有配置或暂时不可用时，学生仍可手动录题、完成本地已审核学习内容，不会被卡在页面中。

## 课程选择范围

数学已登记北师大版七年级上册六章：丰富的图形世界、有理数及其运算、整式及其加减、基本平面图形、一元一次方程、数据的收集与整理，每章四个知识点组。第一章保留原有互动诊断；第二至第六章每个知识点提供 10 道首测题、分步讲解与错题复盘、10 道独立过关题。

以下语文、英语能力目前保留供后续开放，不在当前学生端展示：英语已按项目内人教版七年级教材接入上册 3 个预备单元、7 个正式单元及下册 8 个单元；语文已按项目内人教部编版七年级上下册各接入 6 个单元。重新开放后可从学科页选择单元，完成基础首测、错题讲解、表达练习和独立过关。四册合计 30 个单元、120 个能力点、240 道原创选择题。基础学习和可信判分无需 API；AI 仅用于可选的表达点评。

第二至第六章的内容与可信答案共用 `shared/curriculum/g7-upper/chapter-*.json`。部署时须保留项目根目录的 `shared` 文件夹及前后端相对目录，不可仅拷贝后端；缺失的正式能力包会在后端启动时明确报错。新题为基于本项目教材目录编写的原创练习，不是教材原题全集。

语文、英语目录和题库共用 `shared/curriculum/language/*.json`，前端显示内容与后端判分读取同一数据源。单元完成、最近学习日期和成长值保存到当前账号；错题可直接加入错题本。表达练习保存为当前单元草稿，可自行检查，也可在配置 AI 后请求建议。基础过关仅代表本项目配套练习通过，不冒充作文、口语或整册能力的正式测评。

“数学 → 章节复习”（`/subjects/math/review`）可随时查看六章讲解与自查练习，不受当天诊断是否已开始的限制；这是复习资料，不计成长值，也不覆盖当天任务。正式诊断在“今天要做”中选择课程，原有已开始/已完成记录保持不变。

选课后，数学诊断任务会保存当天的课程、章节和知识点快照；切换课程只会更新尚未开始的任务，已经开始或完成的任务继续按原快照完成。首次尚未选课时，后端会明确返回“需要选择课程”的提示，而不会悄悄发放固定演示任务。

## 第一次启动

需要本机安装 Python、Node.js 和 pnpm。当前电脑已具备这些工具；换电脑时请先用 `python --version`、`node --version`、`pnpm --version` 确认，Node.js 本身不保证附带 pnpm。项目已有 pnpm 锁文件，使用 pnpm 可保持依赖安装方式一致。学生端的账号、任务、草稿和错题默认保存在 `backend/data/ai_coach.db`，不需要先安装 PostgreSQL。

先启动后端：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
if (-not (Test-Path -LiteralPath .env)) { Copy-Item -LiteralPath .env.example -Destination .env }
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

再新开一个终端启动前端：

```powershell
cd frontend
pnpm install
pnpm dev
```

打开 [http://localhost:3000](http://localhost:3000)。个人学生选择“学生注册”，注册后进入首次学习访谈；个人 AI 设置在右上角账号菜单中。班级首次使用时选择“首次设置教师”，再进入“学生管理”单个或批量创建学生（每批最多 50 人）；设置完成后首次入口自动隐藏。系统没有预置默认账号。

## 局域网或公网部署前（必做）

上面的启动方式仅面向同一台电脑的本机使用。只要后端会被其他设备访问，就不要保留示例中的开发环境。先在服务器 `backend/.env` 中设置：

```text
APP_ENV=production
BOOTSTRAP_SETUP_CODE=请填写一段高强度且只用于首次初始化的随机字符串
```

首次创建教师账号时，在页面填写这段初始化码；教师创建成功后无需再使用它。若生产环境没有设置该值，系统会拒绝创建首个教师账号，而不是允许任意访问者抢先创建。不要把后端端口直接暴露到公网；应由可信反向代理提供 HTTPS，并限制可访问来源。

## AI / OCR 分两种配置方式

自主注册学生：在学生端“AI 设置”（`/ai-settings`）填写自己的服务商、模型和 API Key。AI 与 OCR 分别配置，OCR 需支持图片输入的模型；费用归个人服务商账号，请和家长确认。密钥只在提交时经过页面，随即清空；后端使用当前 Windows 运行账号的 DPAPI 加密保存，不写浏览器缓存，也不回显。个人配置缺失时不会借用教师密钥；仍能本地练习、手动整理错题。当前支持页面列出的官方兼容接口，不支持任意自定义转发地址。

教师创建的学生：无需填写个人 API，也不能切换为个人配置；继续使用下列服务器统一配置。

教师统一 API 不在学生浏览器填写。将 `backend/.env.example` 复制为 `backend/.env`（已有配置时直接编辑，勿覆盖）后，在该文件填写：

```text
LLM_ENABLED=true
LLM_PROVIDER=
LLM_API_BASE_URL=
LLM_API_KEY=
LLM_MODEL=

OCR_ENABLED=true
OCR_PROVIDER=openai_compatible_vision
OCR_API_BASE_URL=
OCR_API_KEY=
OCR_MODEL=
```

`LLM_PROVIDER` 填写服务名称或 `openai_compatible`。LLM 和 OCR 都需要支持 OpenAI 兼容 Chat Completions 的服务；`*_API_BASE_URL` 填服务商提供的 **HTTPS 基础地址**，通常以 `/v1` 等版本路径结尾。系统会自动追加 `/chat/completions`，请勿重复填写这个后缀。`*_MODEL` 必须填写服务商实际开通的模型标识；OCR 模型还必须支持图片输入。

填写后重启后端，再在教师端“AI 设置”点击“重新检查状态”。页面会显示服务是否启用、配置是否完整，不会显示、保存或回传密钥。随后用一次实际答疑或错题识别确认外部服务连通。

## 数据与安全边界

- 密码使用 scrypt 散列，数据库不保存明文密码。
- 登录令牌只通过 HttpOnly Cookie 留在浏览器，数据库只保存令牌哈希。
- 连续 5 次登录失败会短时限流；生产环境的首次教师创建需要服务器初始化码。
- 教师只能管理自己创建的学生；学生之间的任务、草稿、错题和图片相互隔离。
- 账号费用归属由后端实际创建来源判定：自主学生只用本人 API，教师创建学生只用统一 API。批量创建单事务完成，冲突时整批回滚；密码只保存散列。
- 个人 API 密文保存在数据库旁的 `.<数据库文件名>.personal-api` 私有目录，应与数据库一起保护和备份。当前仅支持 Windows 单进程服务；变更机器、Windows 运行账号或数据库绝对路径后不能直接沿用密文，应先规划重新配置。非 Windows 会安全拒绝保存，不降级存明文。
- 公开注册有单进程可信连接来源限流（15 分钟 10 次）。本机 BFF 共享连接来源；公网高并发注册应接入可信网关限流和防自动化措施，不直接信任用户提交的转发头。
- 同一浏览器多标签页切换账号时，页面会携带自己启动时看到的用户编号；若它与当前会话不一致，后端会拒绝该请求，避免旧标签页把草稿或上传结果写入新账号。
- 错题图片只允许 JPG、PNG、WebP，单张最大 5MB；未确认的临时图片 24 小时后自动清理，错题列表不包含图片二进制。
- AI/OCR 返回结果必须由学生确认，系统不会把识别文本自动保存为错题。
- 为防止重复消耗模型额度，后端按学生账号分别限制 OCR、错因分析、答疑和变式出题的短时间调用；超限会返回可等待的提示。同一暂存图片的 OCR 结果、同一错题已完成的分析会直接复用，不会重复调用模型。
- 这套限流目前是单个后端进程内的保护。日后使用多进程或多服务器部署时，应在网关或共享存储增加统一限流，不能依赖浏览器控制。

## 验证命令

以下命令使用 Python 自带 unittest，无需 pytest。后端接口测试还使用测试环境中的 `httpx`；当前电脑已具备它，换电脑复现测试前需单独准备该测试工具（应用运行本身不依赖它）。

```powershell
cd backend
python -m unittest discover -s tests -v

cd ..\frontend
pnpm exec -- node --test tests/*.test.mjs
pnpm type-check
pnpm build
```

旧 `database/` 中的 PostgreSQL 建表文件仍保留给历史资料迁移使用，但不属于当前学生端首次启动的必需步骤。

## 教师知识库

教师登录后进入 `/teacher/knowledge`，按“上传资料 → 教材范围核对 → 题目审核 → 原题／AI 变式／混合组题 → 教师预览”整理教学资源。题库与教材分栏管理，资源按教师隔离。

本轮题组不自动发布给学生。当前自动出题范围为已登记的北师大版七年级上册课程；AI 结果必须人工审核，复杂图形和 Word 公式保留明确的核对限制。

详细使用说明、已验证结果、尚未完成的浏览器／真实模型验收，以及备份位置见 [教师知识库验收说明](docs/teacher-knowledge-acceptance.md)。
