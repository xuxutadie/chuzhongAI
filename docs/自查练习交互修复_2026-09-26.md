# 自查练习交互修复

## 学生操作

数学学习 → 章节复习 → 自查练习。点击答案后提交检查，显示对错、正确答案与解析；答错自动进入错题集，来源为“自查练习”。可再练一次，但不会因一次答对删除旧错题，也不会推进首页今日任务或增加成长值。

## 实现边界

- 复用现有可信题库、服务端判分和错题集记录，无数据库结构变更、无新增依赖。
- 单选和判断使用原生单选框，多选使用复选框，整行可点击，支持键盘焦点与选中高亮。
- 提交过程中锁定答案；网络失败后保留同一答案与请求编号，防止重复收集。重新练习使用新编号。
- 新增 POST `/api/v1/me/learning/self-check/answers`，前端经现有登录代理访问。服务端校验学生身份、题目归属、选项和请求重放，不接受客户端判分。
- 若错题先前被用户删除或抑制，不假称已重新入库。

接口设计技能用于复用鉴权和幂等边界；前端界面技能用于选择控件、键盘操作、加载及失败反馈；测试先行用于验证新交互和服务端闭环。
