# 教师知识库：本轮交付与验收

日期：2026-09-28。范围：已确认规格的第一阶段，教师私有知识库；不接入学生发卷和每日学习替换。

## 使用入口

教师或管理员登录后，左侧选择 **知识库**：`http://localhost:3000/teacher/knowledge`。
学生无权访问教师知识库。不同教师的原件、图片、题目、任务及题组均隔离；管理员也不能通过此接口读取其他教师的私有资料。

建议按顺序操作：

1. 上传资料：选择 PDF、DOCX 或图片。“本地提取”不调用模型；“AI 整理”使用当前教师的 AI/OCR 服务。
2. 教材：建立教材，附加已提取文件，选择实际来源页或段落，核对知识点及前置知识，保存并审核章节。
3. 题库：核对识别草稿或手动录题；补齐答案、解析、配图与教材范围，明确确认后审核入库。
4. 出题：选择原题、AI 变式或混合，设置用途、题量和常规／进阶／挑战难度。无参考题时须明确允许依据已审核教材补题。
5. 处理任务：完成后可将本次组合保存为题组。AI 新题仍须在题库审核。
6. 我的题组：查看试题、答案与来源，审核题组。修改题目后不会偷偷替换历史版本；使用“更新为当前已审核题目”，再重新预览审核。

## 当前支持与限制

- PDF / DOCX 文档单个最多 20 MB，PDF 最多 50 页；图片最多 5 MB；一批最多 10 个文件、200 道识别候选；一次组题最多 50 道。
- 支持 PNG、JPEG、WebP；旧 `.doc` 需先另存为 `.docx`。损坏、加密、压缩炸弹、过大图片等由本地受限解析器拒绝。
- 当前已登记可用于自动出题的范围：**北师大版七年级上册六章、24 个知识点**，与已有系统课程目录一致。其他年级／教材可以保留资源草稿，但没有可靠知识点映射时不能审核为自动出题范围。
- 标题候选只从原文可定位的章／节标题提取，不能自动变成已审核章节。教材原文和教师转写笔记是有限上下文，不发送整库或学生身份信息。
- Word OMML 公式会显示人工核对提示；自动整理不会忽略公式继续生成。可先转成 PDF，或手工录入。含数学图形的 PDF 页会请求 OCR 图文核对；扫描教材没有可靠文字时须补充核对后的原文／笔记。
- 变式暂不自动渲染新几何图。需要图但没有可靠新图的题目保留为待补图草稿，无法审核；不能沿用数值不一致的原图。
- 配图为私有、清洗后的 PNG。原件下载与图片读取都再次鉴权；资源引用随题目修订、拆分和合并保留。
- 教师 AI 配置独立加密，不读取学生配置，不静默回退其他教师／管理员额度。管理员使用已有服务器配置。
- 取消尚未提交结果的任务会阻止写回；已经发送到模型服务的请求可能仍产生供应商费用。可重试失败单元，已完成结果不重复执行。
- 本轮题组**仅教师保存、审核、预览**；发给学生、替换现有诊断／日练、学生作答回收是后续阶段。
