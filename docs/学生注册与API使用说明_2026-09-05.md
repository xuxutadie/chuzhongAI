# 学生注册与 API 使用说明

## 两种学生账号

| 使用方式 | 如何获得账号 | AI / OCR 由谁提供 |
| --- | --- | --- |
| 自主学习 | 登录页选择“学生注册” | 学生自己的服务商 API，费用由本人账号承担 |
| 班级学习 | 老师在“学生管理”单个或批量创建 | 教师/平台统一配置，学生不填写个人密钥 |

两种账号由后端依据真实创建来源判定，不能通过浏览器参数把自主账号改成使用教师额度。

## 学生自主使用

1. 打开登录页，选择“学生注册”，填写称呼、年级、账号和两次密码。称呼可以用昵称。
2. 注册成功后自动进入“我的 AI 设置”。
3. 分别设置文字 AI 和图片 OCR：选择服务商，填写该服务商实际开通的模型名称与 API Key。OCR 必须选择支持图片输入的模型。
4. 密钥输入框不会回显已保存值；同一服务商下留空表示保留，切换服务商需要重新填写。
5. 配置保存只代表字段完整、加密保存成功，并非服务商连接或额度已经验证。实际提问/识题时才会向外部服务发请求，可能产生费用，应先与家长确认。
6. 没有 API 时可以先去学习，使用本地已审核题目、手动整理错题；AI 功能会提示先配置，不会悄悄使用老师的密钥。

API Key 不是本项目的登录密码。不要把密钥放进截图、聊天或题目内容中。

## 教师批量创建

“学生管理 → 批量创建学生”支持每批最多 50 人，按行填写：

```text
账号,学生称呼,独立初始密码,年级（可选）
```

可以从表格复制制表符分隔的内容；也支持中英文逗号。无需表头，不支持包含分隔符的字段。请为每人设置不同密码，并通过安全渠道单独交付。成功后页面清空名单，不回传、下载或显示后端保存的密码。

有任何重复账号或不合规字段时，整批不创建，不会只创建前几人。自主注册学生不出现在老师的名单中，也不能由老师重置密码或查看私人数据。

教师统一 API 仍在服务器环境配置，教师“AI 设置”只展示脱敏状态。本次未改动 `.env`。

## 安全与当前部署边界

- 所有 AI 实际调用，包括答疑、OCR、错因分析、数学变式，按当前登录学生解析配置。
- 个人 API 仅允许列表中的官方 HTTPS 地址；模型请求不跟随重定向，避免将密钥发送到另一站点。
- 个人完整配置使用 Windows DPAPI 加密，保存在数据库旁 `.<数据库文件名>.personal-api` 目录，不存浏览器缓存、不在状态响应或格式错误中回显。
- 密文绑定当前服务器 Windows 运行账号、数据库绝对路径和学生编号。更换机器、运行账号或移动数据库前，须规划重新配置；损坏密文不会被静默删除。Windows 加密与解密的绑定要求见 [Microsoft 官方说明](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptunprotectdata)。
- 当前支持 Windows 单进程本机部署，不支持非 Windows 明文降级。多实例上线需要独立的跨进程密钥存储及写锁方案，不能直接复制当前密文当成通用云端密钥服务。
- 公开注册每个可信连接来源 15 分钟最多 10 次；本机 BFF 共享来源。公网班级规模使用前需接入可信网关限流、防自动化注册措施和 HTTPS。
- 本次没有新增数据库字段或依赖，已有教师和学生记录保持兼容。

## 已覆盖的验证范围

注册与重复账号、身份字段注入、教师批量事务回滚、限流、个人/统一 API 隔离、四个 AI 入口的实际凭据选择、配置响应脱敏、密文存储与读取、手机页面和保存/清除交互均纳入测试。外部调用使用假响应，未使用真实付费 API，也不把“配置已保存”当作“外部服务已验证”。

本轮结果：后端 116 项、前端 201 项测试通过；生产构建通过。隔离账号库的真实浏览器流程通过，包括注册、两个账号的密钥隔离、保存/刷新/清除、每批 2 人的教师创建及学生登录、320/375/768/1024 像素排版、后端重启读取配置。`localhost` 和 `127.0.0.1` 的注册均通过同源校验。
