# 学习工作台 UI 视觉规范

本轮使用 UI/UX Pro Max 的语义配色、视觉层次、可读性和移动端检查方法，针对初中学生的长时间学习场景调整为清爽明亮的学习工作台。不增加组件库、网络字体或图片依赖。

## 配色与层次

| 用途 | 颜色 | 应用 |
|---|---|---|
| 固定导航 | `#172f4b` 深蓝 | 侧栏、品牌区 |
| 主操作 | `#245dcc` 蓝 | 选课、诊断、开始任务、选中态 |
| 学习成长 | `#087565` 青绿 | 完成状态、成长摘要、记录区 |
| 错题复习 | `#b45029` 暖橙 | 错题新增、保存与复习提示 |
| AI 帮助 | `#6948b5` 紫 | AI 入口、帮助及配置区 |
| 页面底色 | `#eef3f8` 浅蓝灰 | 页面内容背景 |
| 内容表面 | `#ffffff` 白 | 题目、表单、普通卡片 |

主任务使用深蓝底色和白色按钮；摘要卡使用浅色整块底色；内容卡使用白色表面、可见边框和轻阴影。颜色用于帮助区分功能，状态仍由文字、勾选或选中边框表示。答题选项采用统一颜色，避免把选项颜色误认为正确与错误提示。

## 组件规则

- 普通卡片圆角 18px，主任务 22px；按钮和输入框约 10–12px。
- 交互区域至少 44px；移动端输入文字使用 16px，减少自动缩放。
- 导航统一为线性 SVG 图标；退出登录与 AI 主入口分开呈现。
- 手机答题操作区随内容排列，不使用遮挡题目的固定底栏。
- 教师端正文卡不再占用装饰色条的 4px 列，避免单字竖排。
- 键盘焦点使用清晰外框；系统要求减少动态效果时关闭工作台装饰动画。

## 后续修改位置

- 全局色值和工作台样式：`frontend/app/learning-theme.css`。
- 登录页独立样式：`frontend/app/login/login.module.css`。
- 导航图标：`frontend/app/components/workspace_icon.tsx`。

`learning-theme.css` 在既有基础样式之后加载，集中管理本轮视觉规则。修改颜色时优先调整文件顶部的变量，避免在各页面分散改色。

## 验证范围

前端 182 项测试和生产构建通过；浏览器检查覆盖登录、教师首次设置表单、首页、今日任务、数学学习、错题、资料、答疑、报告、教师管理和 AI 设置。检查了 375、768、1024、1440px 宽度，以及横屏布局；教师卡和能力卡增加了正文宽度检查。

抽检正文、导航、主按钮和语义色卡的文字对比：正文/白卡 6.49:1，主按钮 5.98:1，错题保存按钮 5.10:1，导航 10.94:1，摘要卡辅助文字最低 5.03:1。这是关键配色检查，不代表已完成全部读屏和无障碍认证。
