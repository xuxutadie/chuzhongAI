前三项当前机器已安装，但此前未列入项目依赖；此次正式声明。pypdfium2 为新增组件。官方 Windows x64 wheel 约3.9 MB，解压后运行时体积更大；部署时需要对应平台二进制，并定期进行安全更新。不启用 JavaScript/XFA 扩展构建。

替代方案：使用远端文档 OCR 服务，可减少本地解析组件，但整份文件需要外发，增加费用、隐私风险和服务商兼容性依赖。本方案先本地提取与渲染，只有教师明确配置并发起识别时才把必要教学页面交给视觉模型。

本地组件不等于可靠 OCR。扫描文字、复杂公式仍可能需要视觉识别；无法读清的题保留原页和疑点，必须经教师核对才能入库和发卷。DOCX 使用段落序号，不虚构 Word 页码。
