# AI初中学习教练系统_学生端开发指令_V1.0

## 一、开发目标

进入第五阶段：学生端AI学习工作台开发。

目标： 建立学生可以真实使用的学习入口。

当前阶段重点：
让学生能够登录系统，查看自己的学习情况，并完成AI学习闭环。

暂不开发： - 家长端 - 教练端完整后台 - 商业收费功能 - 完整知识库RAG

------------------------------------------------------------------------

## 二、学生端核心定位

学生端定位：

AI个人学习驾驶舱

帮助学生完成：

了解自己 → 制定计划 → 学习执行 → 获得反馈 → 持续成长

------------------------------------------------------------------------

## 三、页面开发范围

### 1. 学生登录页面

功能： - 授权码登录 - 学生账号登录 - 基础身份验证

记录： - 学生姓名 - 年级 - 学校 - 学习目标

### 2. 学习首页

页面名称：

我的学习星球

展示： - 学生信息 - 学习等级 - 成长值 - 今日任务 - 学习趋势

今日任务示例： - 数学训练30分钟 - 英语词汇20分钟 - 语文阅读20分钟

### 3. 学习画像页面

展示： - 数学能力 - 英语能力 - 语文能力

包含： - 当前优势 - 薄弱方向 - AI建议

### 4. AI学习助手页面

功能： - 学习问题咨询 - 错题分析 - 学习方法咨询

要求： AI采用教师式引导，不直接机械输出答案。

### 5. 今日学习计划页面

展示： - 学科 - 任务内容 - 预计时间 - 完成状态

学生可以： - 开始任务 - 标记完成 - 上传反馈

### 6. 成长报告页面

展示： - 学习完成率 - 能力变化 - AI建议

支持： 日报告、周报告、月报告

------------------------------------------------------------------------

## 四、前端设计要求

基于现有 frontend 项目开发。

风格： AI科技感 + 成长游戏化。

视觉： - 深色科技背景 - 数据卡片 - 成长等级 - 知识图谱元素

避免传统教育平台风格。

------------------------------------------------------------------------
