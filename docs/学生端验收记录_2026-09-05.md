# 学生端验收记录

首次验收日期：2026-09-05；语文、英语课程复验日期：2026-09-06。当前交付面向同一台电脑上的本地使用，前端端口为 3000，后端端口为 8000。

## 已完成的学生使用流程

1. 首次可创建教师/家长管理账号，再由管理账号批量创建学生；学生也可自主注册。教师创建的学生使用教师统一服务，自主注册学生按需填写自己的 AI 与 OCR API。
2. 学生首次进入首页时选择已导入课程的知识点；未开始的任务可调整课程，已开始的任务按原课程快照继续。
3. 题干、立体模型和截面说明使用同一题目配置；圆柱题显示圆柱，辅助图形不再重复要求作答。
4. 学习状态和草稿归属于当前账号；重新登录或刷新后从服务端恢复，任务完成由服务端重新核验。
5. 错题本支持拍照/选图上传、手动录入、OCR 待确认结果、确认保存和后续 AI 错因分析；未配置服务时保留可操作的手动路径。
6. 手机端保留可访问导航，答题按钮排列在选项后方，不覆盖图形或选项。
7. 英语、语文均可自由切换上下册、搜索并进入任意单元；每个单元包含 4 道首测、对应讲解、表达练习和 4 道独立过关题，基础学习不依赖 API。
8. 语言单元支持账号级草稿、断网草稿继续编辑、过关服务端核验、完成历史和教材真实页码跳转；跨午夜不会把新任务写入旧日草稿。

## 第一次使用

打开 `http://localhost:3000/login`。学校或家庭统一管理时，选择“首次设置教师”，创建管理账号，再进入“学生管理”创建学生账号；独立使用时可直接选择“学生注册”。自主注册后可以先跳过 API 设置，完成本地课程练习，再按需回来填写个人 AI 与 OCR 服务。

当前真实课程包括北师大版七年级数学上册六章，以及人教版七年级英语、语文上下册。英语上册 10 个单元、下册 8 个单元，语文上下册各 6 个单元，共 30 个语言单元、120 个知识点和 240 道原创首测/过关题。学生可从首页学科入口直接选择语文或英语内容，不必先选择数学课程。

## 填写 AI 与 OCR

教师统一配置可参考 `backend/.env.example`（若已有配置文件，不要覆盖）填写 LLM 和 OCR 服务，并在教师端“AI 设置”检查状态。自主注册学生直接在“我的 AI 设置”里分别填写 AI 答疑与 OCR 服务；输入框已预留，密钥提交后不会回填到浏览器。

OCR 当前支持 OpenAI 兼容视觉接口，服务标识填写 `openai_compatible_vision`，模型必须支持图片输入。具体字段和启动步骤见根目录 `README.md` 与 `backend/README.md`。

真实服务密钥尚未提供，因此未声称已验证外部服务连通性、真实图片识别准确率或实际模型回答质量。未配置时页面明确提示，并可继续使用已审核本地学习内容和手动错题录入。

## 使用边界

- 同一账号两个标签页同时修改课程时，旧页面可能需要刷新或重新选择；服务端会拒绝不属于当前任务课程范围的完成记录。
- 当前为本地单后端进程运行方式。局域网/公网部署需按 README 设置生产环境、首次初始化码和 HTTPS；本次未进行公开部署。
