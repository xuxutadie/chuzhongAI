# 学生学习工作台框架设计

## 目标

将现有学生端从顶部五页导航改造成高密度、多入口的学习工作台。借鉴资料库工作台的信息组织方式，但以 AI 学习教练闭环作为核心，而非资料堆叠。

## 范围

- 以左侧导航、顶部状态栏和主内容区组成统一学生端框架。
- 保留现有仪表盘、学习分析、今日任务、AI 教练、成长报告五个页面。
- 新增学科学习、错题本、资料中心、练习中心四个框架页，展示可点击的入口与示例数据。
- 重组仪表盘，展示今日任务、学习进度、学科进度、近期错题、AI 建议和成长趋势。
- 使用静态演示数据适配层，预留后续 API 替换点。

本轮不包含 OCR、真实教材/题库导入、文件上传、真实数据库读取、真实考试倒计时、后端 API 调用或 Agent 业务逻辑变更。

## 信息架构

左侧导航分为四组：

1. 学习总览：仪表盘、学习分析、成长报告。
2. 学科学习：数学、英语、语文。
3. 学习工具：今日任务、练习中心、错题本、资料中心。
4. AI 教练：教师式答疑入口。

桌面端始终显示侧边栏；窄屏端转换为顶部横向导航，避免遮挡内容。顶部状态栏显示学生姓名、年级、等级、成长值和 AI 教练快速入口。

## 组件边界

- `StudentWorkbenchShell`：全局布局、背景与主内容容器。
- `StudentSidebar`：基于导航配置渲染导航分组和当前页状态。
- `StudentWorkspaceHeader`：学生状态和 AI 快捷入口。
- `WorkbenchPage`：页面的标题、说明与内容插槽。
- `StudentDashboard`：仅负责仪表盘卡片，不负责导航或页面外壳。
- `workspace-data.ts`：集中维护导航、学科、统计、错题和资料的演示数据。

## 交互和数据边界

- 所有导航项必须使用 Next.js `Link` 跳转至真实路由。
- 当前页面通过 `usePathname` 高亮。
- 学科、错题、资料和练习页是独立路由，不在单页内堆叠。
- 演示数据与组件分离；未来以 API 返回值替换数据模块，不改变布局组件的 props 形状。

## 视觉原则

- 延续深绿学习成长主题与首页粒子背景，但降低装饰比例。
- 主阅读区优先展示任务、进度和建议，使用紧凑网格与 8px 以下圆角。
- 数学、英语、语文分别使用蓝、绿色、金色作为辅助色，避免单一色相占满页面。
- 移动端保证导航可横向滚动，卡片切换为单列，文字不截断。

## 验收标准

- 十个导航入口均可点击，并在正确页面高亮。
- 桌面端显示侧边栏和顶部状态栏；移动端无横向溢出。
- 仪表盘包含任务、学科、错题、AI 建议和成长趋势五类信息。
- 新增页面均为可访问路由，不出现空白页面。
- `pnpm run type-check` 和现有 Three.js 测试通过。
