# 学习流程一致性修复设计

## 目标

修复“今天要做”数学学习流程中课程选择、题干、辅助图形、互动挑战与计分状态彼此脱节的问题。学生在每一步只会看到与当前题目一致的一套内容，不会重复答题，也不需要人工发现同类错误。

## 范围

本轮覆盖北师大版七年级上册第一章“丰富的图形世界”的 4 个知识点、40 道本地题和现有互动课件。

- 选择页显示真实可选的教材、册别、章节和知识点；当前仅提供的数据仍是北师大版七年级上册第一章，界面必须明确显示此范围，不能伪装成可选的全量课程。
- 普通看图题只展示与题目 `visual` 完全匹配的辅助图形，不显示课件的即时挑战，不参与互动计分。
- 互动题只展示自身配置的模型、操作说明和即时挑战；互动挑战成功即写入当前题答案，外层按钮只负责进入下一题。
- 图形场景必须由题目 `visual` 决定：立体模型使用 `solid`；截面题同时使用 `solid` 和 `planePreset`；展开图和三视图使用自身的 `netId` 或 `structureId`、`view`。
- 对所有本地题库执行静态一致性校验；题目所需图形不被现有课件支持时，拒绝该题并在开发测试中失败，而不是回退展示正方体。

## 架构

新增一份纯前端的“题目展示描述”适配层，把 `MathQuestion.visual` 转为受白名单限制的 iframe 查询参数。`MathQuestionRenderer` 不再用知识点包的默认 `interaction.section` 决定普通题画面。互动课件从查询参数读取展示描述：预览模式只渲染图形，互动模式才渲染操作和挑战。

课程选择使用当前能力包的元数据生成级联选择项。数据尚未覆盖的课程不显示为可选择项；这样既可让学生选择当前已支持的章节，也为后续导入教材题包保留扩展入口。

## 约束

- 不新增第三方依赖。
- 不修改 `.env`、密钥、后端接口或数据库结构。
- 不伪造尚未导入的教材、章节或题目。
- 保持既有本地题库和学习会话兼容；已开始的当天会话可继续完成。
- 所有新增逻辑先有失败测试，再写实现。

## 验收标准

1. 圆柱、球、圆锥、正方体和长方体题分别展示对应模型。
2. “平行于圆柱底面截圆柱”展示圆柱与圆形截面，题内提示和选项不再出现正方体或正方形。
3. 普通图形题不会同时出现 iframe 内挑战和外层相同选择题。
4. 8 道互动题的挑战 ID、图形类型和题干均能通过一致性校验。
5. 40 道本地题均通过题目—图形—场景映射校验；任何不支持的映射使测试失败。
6. 学生可在当前已支持的“数学 → 北师大版 → 七年级上册 → 第一章”范围内选择知识点，且界面清楚标注可选范围。
7. 前端类型检查、全部前端测试、生产构建和浏览器实际访问均通过。
