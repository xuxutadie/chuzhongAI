# 学生端每日学习闭环与明亮模式设计

## 目标

让刚进入初一的学生不需要阅读说明书，也能按照“登录、完成当前任务、查看反馈、继续下一项、完成今日目标”的固定顺序独立学习。

## 设计原则

- 首页只突出一个当前行动，不让多个功能争夺注意力。
- 当前任务完成前，后续任务保持锁定；完成后自动解锁下一项。
- 首页、任务页、互动课件和学习报告读取同一份进度。
- 当前调试阶段使用浏览器本机持久化，并通过独立数据接口层为后端接入预留边界。
- 学生页面不出现“Agent、框架、后续接入”等开发语言。
- 全站使用明亮模式，正文保持高对比度，以蓝、绿、黄、珊瑚色区分功能，不使用单一绿色主题。
- 不新增第三方依赖，不修改现有 Agent API。

## 学习流程

1. 学生登录后进入学习首页。
2. 首页显示今日总目标、已完成数量和唯一的“开始第 N 项”按钮。
3. 点击按钮后，任务自动进入进行中状态并打开对应学习内容。
4. 数学使用现有互动课件；英语和语文使用三步引导练习。
5. 学生完成观察或阅读、即时自测和一句学习总结后，系统记录完成状态。
6. 返回任务页时自动显示下一项，首页和报告同步更新。
7. 三项全部完成后显示今日总结、成长值和复习建议。

## 状态模型

每日学习进度包含日期、任务状态、任务反馈和今日新增成长值。任务原始状态只保存“未开始、进行中、已完成”；“待解锁”由任务顺序和前置任务完成情况计算，避免保存互相矛盾的状态。

进度通过 `LearningProgressProvider` 提供给学生端页面。浏览器存储只是当前调试适配器，后续可替换为后端接口，而页面组件不需要重写。

## 页面调整

- 登录页：改为明亮欢迎页，使用“开始今天的学习”等学生语言。
- 首页：增加今日主任务区、三步任务路线和实时完成进度，弱化次要数据。
- 今日任务：只允许操作当前任务，后续任务显示解锁条件。
- 任务内容：补齐英语词汇与复述、语文阅读理解的真实练习。
- 互动课件：提交学习反馈时同步完成对应数学任务，并提供回到下一项的入口。
- 学习报告：日报告使用真实今日完成率，不再显示固定的 82%。
- 专项练习和错题本：删除开发占位文字，提供清楚的学生行动入口。

## 验收标准

- 刷新或跨页面返回后，今日任务状态不丢失。
- 未完成第 1 项时，第 2、3 项不能开始。
- 不完成学习内容不能直接把任务标记为完成。
- 完成任一任务后，首页、任务页和日报告显示相同进度。
- 英语和语文任务均包含学习、自测、总结三个步骤。
- 桌面端和手机端首屏都能看到当前目标和主按钮。
- TypeScript 检查、生产构建和关键浏览器流程通过。
