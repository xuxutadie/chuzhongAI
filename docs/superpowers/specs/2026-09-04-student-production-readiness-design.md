# 学生端真实可用闭环设计

## 目标

将当前“演示数据 + 浏览器本地状态”的学生端改造成可在本机或校内服务器上持续使用的学习系统：学生有独立账号和数据；学习进度、错题和草稿可恢复；评分不会因图形失败而虚高；AI 与 OCR 在未配置时安全降级，配置后可通过同一后端服务启用。

用户已明确授权连续执行本设计，不逐项等待确认。API 密钥不写入仓库、不修改现有 `.env`；页面和 `.env.example` 均保留明天可填写的位置。

## 已知约束与决定

1. 不新增第三方依赖。默认持久化采用 Python 标准库 `sqlite3`，避免要求本机先安装 PostgreSQL。
2. 已有 PostgreSQL 学习仓储代码保留，新的学生工作台采用独立、可测试的 SQLite 仓储；旧版按 URL 传入学生 ID 的公开接口撤下，避免伪造身份访问数据。
3. 登录使用后端签发的随机会话令牌；前端只保存 HttpOnly Cookie，不在浏览器存储密码或令牌。
4. 首次运行创建教师/家长账号；之后由教师创建学生账号。学生不可见 AI 密钥设置。
5. 服务器的 `.env` 是长期 AI/OCR 配置来源；教师页面可做一次临时连通测试，临时密钥仅驻留服务进程内存，重启后失效。
6. 默认 AI/OCR 未配置时，学习、手工录题和本地审核题库仍可用；界面须明确说明需要教师配置，而不是假装已经识别或分析。
7. OCR 先支持 OpenAI 兼容视觉接口：识别结果必须经过学生确认和编辑后才能保存。对不兼容服务保留自定义 HTTPS 接口位置，不承诺未填写配置时识别成功。

## 用户角色与学习路径

### 教师/家长

1. 首次运行创建管理账号。
2. 创建学生账号、重置密码、查看配置状态。
3. 在“AI 设置”中填写或测试临时模型与视觉识题配置；密钥不会显示给学生。

### 学生

1. 以账号和密码登录，服务端恢复自己的工作台状态。
2. 从当前任务进入正确的学习内容；数学五步流程、英语/语文任务与首页进度使用同一份任务状态。
3. 刷新或暂时离开后恢复当前步骤、答案、反思和互动完成标记。
4. 图形加载失败时获得等价文字替代题，不能靠跳过题目获得过关。
5. 上传照片后，如果 OCR 已配置则确认识别结果；未配置时明确要求手工录入，不能把空图片错误送给 AI。

## 后端边界

新接口统一置于 `/api/v1`，返回 `{detail: string}` 的明确错误。前端仅通过同源 Next 代理调用，代理读取 HttpOnly 会话 Cookie 并附带后端授权头。

| 能力 | 后端接口 | 访问者 |
|---|---|---|
| 首次创建教师、登录、登出、当前会话 | `/auth/bootstrap`, `/auth/login`, `/auth/logout`, `/auth/me` | 相应用户 |
| 管理学生 | `/teacher/students` | 教师/家长 |
| 工作台状态与草稿 | `/workspace/state` | 当前学生 |
| 错题增删查与分析 | `/wrong-questions`, `/wrong-questions/{id}/analyze` | 当前学生 |
| AI 答疑与图片识题 | `/assistant`, `/ocr/recognize` | 当前学生，依赖配置 |
| AI/OCR 配置状态和临时测试 | `/teacher/ai-config/*` | 教师/家长 |

SQLite 表包括 `users`、`sessions`、`workspace_states`、`wrong_questions`。所有记录都以真实学生 ID 过滤。图片数据由后端限额保存，不再占用浏览器 LocalStorage。

## 前端边界

1. 新增同源 API 客户端与会话 Provider；路由布局在没有会话时跳回登录页。
2. `LearningProgressProvider` 以服务端工作台状态为唯一来源；数学工作区、互动课和引导任务只通过 Provider 保存状态。
3. 首页的主按钮打开当前真实任务链接；数学五步学习完成后完成第一个任务并解锁下一项。
4. 题目评分要求全部计划题目有有效结果；图形错误只能进入等价备用题或“稍后继续”，不能减少分母。
5. 错题本显示真实学生记录，删除有确认和撤销窗口；示例数据不进入学生记录。
6. 手机导航改为明确可操作的折叠导航；保留键盘、读屏和减少动态效果支持。

## AI/OCR 配置

`backend/.env.example` 预留以下字段，不包含真实值：

```dotenv
APP_SESSION_SECRET=请替换为随机长字符串
AI_PROVIDER=OpenAI
AI_API_KEY=
AI_MODEL_NAME=
AI_BASE_URL=https://api.openai.com/v1
OCR_PROVIDER=openai_compatible_vision
OCR_API_KEY=
OCR_MODEL_NAME=
OCR_BASE_URL=https://api.openai.com/v1
```

教师页面显示“已配置/未配置”，但绝不回显密钥。临时测试使用本次请求提供的密钥，测试完成后仅保留 30 分钟的内存会话。

## 验收标准

1. 未登录访问学生页面会跳转登录；两个学生不会看到或覆盖彼此的数据。
2. 首页任务、数学五步学习、英语/语文任务和成长值保持一致；所有答错不能直接完成。
3. 刷新后恢复未完成学习；跨天历史仍可被报告读取。
4. 所有图形题未产生有效作答时不能判定过关；加载失败有可用替代路径。
5. 图片错题可在未配置 OCR 时安全手工补录；配置 OCR 后可识别、确认、分析并保存状态。
6. 当前运行端口统一为后端 `8000`，前端不再硬编码 `8001`。
7. 后端单元/接口测试、前端单元测试、类型检查、生产构建和真实浏览器主路径均通过。

## 边界

- 必须做：中文界面与注释；测试先行；密钥不写入源码或日志；错误向学生给出可行动说明。
- 可以做：为现有课程目录逐步导入更多已审核课程；在无 AI 配置时继续使用本地题库。
- 不做：自动写入用户 `.env`、提交 Git、接入支付、擅自使用外部 API 或上传学生数据到未经配置的服务。
