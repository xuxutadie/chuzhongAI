# 分组式侧栏导航轮设计

## 目标

为学生学习工作台的左侧导航加入参考 `OptionWheel` 的弧形聚焦效果，同时保留现有中文分组、导航文字和页面路由。

## 范围

- 保留四个分组：学习总览、学科学习、学习工具、AI 教练。
- 每个分组独立渲染为纵向弧形导航轮。
- 当前路由在所属分组中居中、高亮且清晰显示；相邻入口按距离逐步倾斜、淡化和虚化。
- 点击入口立即进入原有页面。
- 桌面端支持鼠标滚轮、拖拽和键盘方向键切换分组内焦点；拖拽或滚动只改变视觉焦点，不自动跳转页面。
- 手机端保留现有可横向滚动的扁平导航，确保所有入口可快速扫描和点击。

## 非范围

- 不新增第三方依赖，不接入音效，不修改导航数据、路由或后端接口。
- 不将全部 11 个入口合并为一个导航轮，避免丢失功能分组和降低可读性。

## 组件边界

新增 `CurvedNavigationGroup` 组件，仅负责单个分组的动画、可访问性与导航链接渲染。`StudentNav` 继续负责品牌、分组遍历与底部提示。导航数据继续来自 `workspace_navigation_model.js`。

## 验收标准

1. 现有 11 个中文入口、4 个分组和对应路由保持不变。
2. 桌面端当前页面链接具有 `aria-current="page"`，且视觉上最清晰。
3. 点击任一入口可以进入原页面；键盘可聚焦并使用方向键调整当前分组焦点。
4. 手机端侧栏不出现重叠、裁切或不可访问的入口。
5. 不产生浏览器控制台错误，并通过现有导航模型测试和 TypeScript 检查。
