# AI初中学习教练系统_学生端功能增强指令_V2.0

## 一、升级目标

当前学生端已完成基础视觉框架，但更偏向展示页面。
本次升级需要将学生端升级为真正可使用的 AI 学习工作台。

核心闭环：

了解自己 → 接收任务 → 执行学习 → AI辅助 → 获得反馈 → 持续成长

------------------------------------------------------------------------

## 二、开发原则

1.  基于现有代码升级，不推翻已有架构。
2.  功能优先，不只优化UI。
3.  保持与Agent系统、数据库、未来知识库兼容。
4.  当前可以使用模拟数据，但必须预留真实接口。

------------------------------------------------------------------------

## 三、首页升级：我的学习星球

首页需要成为学生每天进入系统的入口。

顶部展示：

-   学生头像
-   姓名
-   年级
-   学习等级
-   成长值

示例：

张同学 初一 Lv3 自主管理者 成长值1250

------------------------------------------------------------------------

## 四、首页核心模块

### 1. 今日学习任务

必须突出显示。

包含：

数学任务： 一元一次方程基础训练 35分钟

英语任务： Unit1词汇训练 20分钟

语文任务： 阅读训练 25分钟

每个任务支持：

-   开始学习
-   完成任务
-   状态变化

完成后增加成长值。

------------------------------------------------------------------------

### 2. AI学习教练入口

增加明显入口：

AI学习教练

支持：

-   学习规划咨询
-   学科问题咨询
-   错题分析
-   学习方法指导

要求：

不是普通聊天机器人，需要体现学生画像和学习记录。

------------------------------------------------------------------------

### 3. 学习能力星球

展示：

数学能力 英语能力 语文能力

使用能力等级：

★★★★★

未来支持知识点地图。

------------------------------------------------------------------------

### 4. 成长系统

增加游戏化机制：

等级：

Lv1 学习探索者 Lv2 习惯建立者 Lv3 自主管理者 Lv4 能力提升者 Lv5
卓越挑战者

成长值来源：

-   完成任务
-   错题复盘
-   学习打卡
-   阶段测试

------------------------------------------------------------------------

## 五、新增页面

### AI学习诊断页面

展示：

-   学生优势
-   薄弱方向
-   AI建议

### 今日计划执行页面

功能：

-   任务列表
-   学习计时
-   完成反馈

### AI学习助手页面

调用Agent接口。

要求：

采用教师引导模式，不直接机械输出答案。

### 成长报告页面

展示：

-   日报告
-   周报告
-   月报告

包括：

-   完成情况
-   能力变化
-   AI建议

### 错题中心

第一阶段：

-   上传图片入口
-   保存错题
-   查看历史错题

后续接入OCR和错题Agent。

------------------------------------------------------------------------

## 六、数据接口预留

使用：

student_profile

learning_task

study_record

growth_record

wrong_question

study_report

流程：

学生端

↓

Backend API

↓

Agent服务

↓

数据库

------------------------------------------------------------------------

## 七、交互要求

禁止只做静态页面。

必须支持：

-   点击
-   页面跳转
-   状态变化
-   数据更新

例如：

任务状态：

未完成

↓

进行中

↓

已完成

------------------------------------------------------------------------

## 八、视觉要求

保持：

AI科技感 + 成长游戏化

方向：

-   深色科技背景
-   数据卡片
-   星球成长元素
-   发光视觉效果

但功能优先。

------------------------------------------------------------------------

## 九、完成标准

学生可以：

✅ 登录系统

✅ 查看学习画像

✅ 查看今日任务

✅ 执行学习任务

✅ 使用AI学习助手

✅ 查看成长报告

✅ 查看错题中心

✅ 获得成长反馈

------------------------------------------------------------------------

## 十、测试要求

创建至少3个模拟学生。

测试：

1.  登录流程
2.  任务生成
3.  任务完成
4.  成长值变化
5.  AI入口调用
6.  报告展示

完成后进入教练端开发。
