# 七年级上册全章学习接入计划

## 范围与依据

补齐项目现用北师大版数学七年级上册第二至第六章，不新增依赖、不改数据库结构、不改 API 配置、不覆盖第一章及既有学生学习记录。

已人工核对本地《教材/北师大版·数学七年级上册.pdf》第 4、5 个 PDF 页面目录。题目为围绕目录知识点编写的原创练习，不冒充教材原题。每章拆为四个适合一次学习的知识点组。

## 实施切片

1. 建立全册内容覆盖和可信判分回归测试，先确认现状缺失。
2. 分章编写共享 JSON 能力包：第二章有理数及其运算、第三章整式及其加减、第四章基本平面图形、第五章一元一次方程、第六章数据的收集与整理。每个知识点含 10 道首测、10 道独立过关题、讲解步骤和易错提醒。
3. 前后端共同读取这批静态内容，避免选课目录与答案表不同步；保留第一章原有题号与备用图形题规则。
4. 在现有学习工作台接入全册查找、针对错题的文字讲解和独立过关题。新题不加载第一章几何互动，不虚构图形操作完成；已有互动课件保留为课外探索入口。
5. 更新学科页与提示，明确现有覆盖范围以及正在进行任务的课程快照不会被改写。
   增加只读章节复习入口，让已有当天任务的学生也能阅读其他章节讲解与自查练习；不计分、不覆盖原任务或学习记录。
6. 自动化校验题号、归属、答案、题量、不同轮次，接口逐章选课与可信判分；使用独立测试库跑浏览器首测失败→讲解→过关→保存，核对手机宽度与刷新恢复。

## 共享数据契约

文件：`shared/curriculum/g7-upper/chapter-N.json`，顶层 `{id,title,packages}`。

每个 package 沿用 MathKnowledgePackage 基本字段：id、subject、grade、semester、textbookVersion、chapterId、title、lessonId、capabilityTags、questions；新包 `learningMode: "explanation"`，省略只适用于第一章的 interaction。新增 `retestQuestions`（10 道）与 `learningGuide: {steps:string[], pitfalls:string[]}`。

题目沿用 MathQuestion 字段，题型含单选、判断、多选，三级难度；题号格式 `g7u-cN-topic-d01` / `g7u-cN-topic-r01`，知识点编号 `g7u-cN-topic`。不使用未注册的视觉参数；题干必须独立可读，条件明确，选项唯一且正确答案全部指向现有选项。讲解包括运算或推理过程，过关题不与首测题干完全相同。

## 验收边界

- 六章可选，所有列出的知识点均有真实题目与针对学习，不出现空白页。
- 新题普通学习和判分不依赖外部 API；AI 提问等仍遵守原个人/教师配置权限。
- 服务端拒绝错答案、假题号和跨章节凭据，旧第一章记录可继续使用。
- 当天已经开始或完成的任务保留原课程快照；不以覆盖旧记录来假装切章成功。
- 不以本次全册基础能力包声称覆盖教材所有习题、所有年级或全部题型。

## 实现依据

共享 JSON 的前端导入采用当前 TypeScript 支持的 import attributes 语法，参考 [TypeScript 5.3 官方说明](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-3.html#import-attributes)。数学运算与原创练习不依赖外部模型生成；接口和数据库继续沿用现有实现。
