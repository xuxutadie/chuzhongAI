## 使用入口

- 正式诊断：学生登录 → 今天要做 → 教材/章节/知识点 → 确认课程内容 → 开始首次测试。
- 随时复习：学生登录 → 数学 → 进入章节复习 → 选择章节及知识点。
- 已开始任务仍按原快照继续；想当天先看其他章，应使用章节复习，不删除原记录。

## 范围限制

本次是项目所用北师大版数学七年级上册基础能力包扩充，不代表其他年级、其他教材版本或教材所有原题均已开发。新增章节以独立可读的文字题为主，没有宣称全部配备动态图形。公网部署安全告警等仍以之前验收文档中的限制为准。
