# 学生端前端

这是 AI 初中学习教练的 Next.js 学生端与同源 BFF。它已经接入真实的教师/学生账号、每日学习路线、草稿、错题本、OCR 确认和 AI 服务状态，不使用演示账号或浏览器内的访问令牌。

## 启动

先按仓库根目录说明启动 `backend`，再在本目录运行：

```powershell
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。学生可选择“学生注册”并设置个人 API；班级使用则先设置教师账号，再单个或批量创建学生。

## 学生可用入口

- `/dashboard`：服务端今日任务、进度与成长值。
- `/today-learning`：北师大版数学七年级上册六章、24 个知识点组的诊断、针对学习与过关测试。
- `/subjects/math/review`：随时阅读章节讲解与自查题，独立于当天任务，不计成长值。
- `/subjects/english`：人教版七年级上下册共 18 个单元，支持搜索、选单元、首测、讲解、表达练习与独立过关。
- `/subjects/chinese`：人教部编版七年级上下册共 12 个单元，显示课文范围并支持同一完整学习流程。
- `/tasks/english-20`、`/tasks/chinese-20`：真实的引导学习活动。
- `/wrong-questions`：拍照/相册/电脑选图、OCR 待确认、手动录入、保存、编辑、分析和删除。
- `/assistant`：通过服务端配置的 AI 答疑；未配置时给出明确的手动学习提示。
- `/ai-settings`：自主注册学生保存自己的 AI/OCR API；教师创建学生只查看统一服务状态，不填写密钥。
- `/materials`：通过白名单与登录校验打开项目内七年级语数外上下册六本 PDF，并链接到语文、英语单元学习。
- `/interactive-lessons`：打开项目内已登记的互动课程。

教师使用 `/teacher/students` 单个/批量创建与重置学生账号，使用 `/model-config` 查看统一 AI/OCR 状态。统一 API Key 仍在后端 `.env` 填写；自主学生通过 `/ai-settings` 单次提交个人 Key，由后端 Windows DPAPI 加密保存，页面提交后立即清空，不在浏览器缓存或状态响应中保存明文。

同机运行时，前端服务器默认访问 `http://127.0.0.1:8000`。仅在前后端分离部署时，才需要为前端服务器设置 `BACKEND_API_ORIGIN`，指向实际后端地址；它是服务端配置，不要加 `NEXT_PUBLIC_` 前缀。

## 安全与离线边界

- 浏览器只持有 HttpOnly、SameSite Cookie；后端访问令牌不进入 URL、localStorage 或前端状态。
- 所有学生请求经同源 `/api` BFF 转发；图片保持原始二进制，不转换为 Base64。
- 当前服务器暂时不可用时，页面可恢复本机草稿，但会明确标识“完成记录尚未提交”，不会伪造完成状态。
- 图形互动失败会给出文字替代题或文字讲解；普通选择题仍保留原有作答规则。
- 第二至第六章使用分步讲解和错题复盘，不加载第一章图形；新章第二、三轮使用本地独立过关题，第一章保留原题重测。未接入的 AI 变式不会混入完成凭据。
- 已开始或完成的当天数学任务保留原课程快照；选课调整用于尚未开始的任务或后续学习，不覆盖旧记录。
- 共享题库位于项目根目录的 `shared/curriculum/g7-upper` 和 `shared/curriculum/language`，构建和部署需连同这些目录一起保留。

```powershell
pnpm build
```
